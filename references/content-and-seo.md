# Product Copy and SEO

Use this reference after the report audit and before writing customer-facing copy.

## Search intent

Identify the concrete product category first. Prefer the phrase a customer would use to find and buy the item, not the factory's internal item name. Validate terminology against current search results or available keyword data when practical.

Choose one primary transactional category phrase, two to four secondary category or feature phrases, and one or two long-tail phrases that combine category, use, and a verified differentiator.

Do not report numerical search volume, traffic potential, or keyword difficulty without a source.

## Required SEO fields

- Product name.
- SEO title, normally concise enough to display well in search.
- H1.
- Lowercase descriptive URL slug.
- Meta description that states product, result, differentiators, and relevant limitation without keyword stuffing.
- Section headings aligned with real customer questions.
- Product specifications.
- Package contents.
- Image alt text describing what is actually visible.

## Product-name pattern

Use this order when natural:

```text
Primary category + defining feature + meaningful included item or size
```

Do not add audience capacity, material, waterproofing, species, certification, or compatibility unless verified.

## Copy architecture

Write copy that can be published directly:

1. Product name and one-sentence value proposition.
2. Five to nine benefit-led bullets.
3. Short product description.
4. Feature sections answering why each verified feature matters.
5. Specifications table using actual measurements.
6. Package contents.
7. Image alt text.

Use benefits to explain verified features, not to invent capabilities. Prefer “water-repellent fabric helps with light moisture” over “fully waterproof.” Prefer “portable carry bag included” over an unmeasured setup-time claim.

## Conflict handling

Inspection reports may show client specification, printed carton marking, and actual measured value. Use the actual measured value in the product specification table. Use a nominal value only when customary and the difference is immaterial. Never silently use a contradicted shipping-mark value.

## Exclusions

Exclude inspection-company branding, report number, factory address, order quantity, AQL methodology, inspector calibration records, defect codes, and repacking notes unless the user specifically needs compliance or sourcing documentation.
